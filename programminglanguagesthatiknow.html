About the programming languages I know:

Python:
It is a popular programming language.It is a high-level and interpreted programming language.It's syntax is almost like plain english.It also has many libraries such as MongoDB,Pandas,Matplotlib,etc.It's execution is slow because it is an interpreted language.

C++:
C++ is a compiled programming language.It is a better version of C.It is used in games such as GTA and also used in some operating systems such as Microsoft Windows.It's execution is very fast.It also supports OOP(Object Oriented Programming).

C#(or C-sharp)
C#(or C-sharp): is a programming language.Even though it starts with C,it's syntax is similiar to java rather than being similiar to C and C++.It's execution is faster than python but slower than C and C++.It was made by Microsoft.

HTML:
HTML is a programming language that is used to program websites.It gives structure to a website.HTML is one of the three programming languages you need to learn to make a website(You can make a website with only two or one of the languages but it will lack either style or functionality).

CSS:
CSS is another language needed to program a website.It gives style to a webpage.Without it,a website would lack style.(However,You can still program a website,the only thing it will lack is colors.)

Javascript:
Javascript is the third programming language you need to learn to make a website.It gives functionality to a website.You can still make a website with only HTML or with only HTML and CSS,but the website will lack functionality.
